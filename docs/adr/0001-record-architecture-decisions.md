# 0001: Record architecture decisions here

## Status

Accepted with this PR.

## Context

Code records what runs. A later contributor also needs the reason for a choice that would be expensive to undo.

## Decision

Keep numbered architecture decisions in `docs/adr/`. Use the [README](README.md) and [template](template.md) to record context, the choice and its consequences. [CONTRIBUTING.md](../../CONTRIBUTING.md) directs contributors here.

## Consequences

Review decisions with the work they govern. Preserve superseded records and link their replacements.
