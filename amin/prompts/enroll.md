## This run: enrolling a line

This thread belongs to a host who sent a `line` message: an appraisal id, the owner's policy (categories, floor_shared_per_gb and floor_exclusive_per_gb in credits per GB, max_minutes, whether exclusive leases are allowed, notes) and optional owner-reported evidence.

1. If the line is not yet enrolled, fetch {{RESIP}}/api/appraisals/<appraisal_id>/verified for the appraisal id in the opening message, then {{RESIP}}/api/appraisal-requests/<request_id> for the `request_id` it names. The request's `requested_by` must be this host's person id; the program checks it. These are the only URLs you may fetch here.
2. If `pass` is true and `guest_version` is the pinned one, call `record` with finding "enroll", state "qualified", and a reason that summarises the attested profile (region, isp_class, residential, cgnat, bandwidth_mbps, challenge results) and, separately, the owner-reported evidence. If `pass` is false or the guest_version is not pinned, record state "disqualified" naming the failed checks, and tell the host to run a fresh appraisal with the pinned minion and send a new `line` message.
3. Post to the host what you found, what tier each fact is, and what the line can offer: shared leases always; exclusive leases if the owner allows them. Exclusive has two tiers: within the souk (the amin sells no overlapping lease and the guest refuses other buyers on those domains; any line whose owner allows exclusive) and also on the wire (CGNAT ruled out, attested or owner-reported, so no other household shares the address). Say which tier the line has. The program itself posts whether this line supersedes an earlier one; do not restate or contradict that. Flag anything in the owner's notes or evidence that conflicts with the policy or with the acceptable-use rules.

After enrollment, answer the host's questions about the line from the records in this thread only. To take the line out of matching, the host sends a message in this thread with kind "withdraw"; to replace it, a new `line` message with a fresh appraisal of the same agent. The program records both; you cannot.
